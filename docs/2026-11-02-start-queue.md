# 중지 VM 순차 시작

클라우드 인스턴스 화면에서 중지된 VM 여러 대를 선택하고 시작 요청을 한 대씩 전송할 수 있습니다. 확인창에는 선택한 대상이 표시됩니다. 부팅 완료를 기다리는 기능은 아니므로 실제 부팅은 겹칠 수 있습니다.

기존 단일 VM 시작 API를 그대로 사용합니다. 권한·프로젝트·한도·승인 조건은 서버에서 기존과 같이 검사합니다. 한 VM의 실패는 개별 결과로 표시하고 다음 요청을 처리합니다. 중복 대상과 중지 상태가 아닌 대상은 요청 전에 거부합니다.

테스트에서는 모의 요청만 사용하며 실제 VM을 실행하지 않습니다.

GitHub는 공개 코드 저장소이고 Gitea는 비공개로 유지합니다. 과거 비공개 아카이브와 운영 데이터·키·환경설정은 공개하지 않습니다.

# 0.3.7 Preview 기능 검증 기록

검증일: 2026-11-21. 독립 Community 소스에서 수행했으며 운영 DB·계정·클라우드 자원은 사용하지 않았습니다.

## 교육 기능 및 Lab Board 제외

- 원본 분리 시 기록한 499개 경로는 교육 제외 목록 182개와 일반 기능 유지 목록 317개로 구분됩니다. `tests/edition.test.mjs`는 유지 목록이 교육 차단 조건에 걸리지 않는지 확인합니다. 이 목록은 분리 당시의 기준이며 모든 경로의 실서비스 실행을 의미하지 않습니다.
- 교육 API·직접 탐색·보고서·교재·교육용 터미널·교육 검증 시드와 강사 공유 WebSocket의 차단을 확인했습니다. 관리자도 차단을 우회할 수 없습니다.
- Lab Board 페이지·API·전용 자산을 일반 사용자와 관리자 모두 사용할 수 없는지 확인했습니다. 원문 커리큘럼 파일은 배포 소스에 없습니다.
- 교육 경로·메뉴를 제외해도 일반 VM 터미널 경로와 소유권 검사는 유지됩니다.
- 공통 DB 호환 테이블, 비활성 공유 코드와 빈 화면 스텁은 남아 있습니다. 기능 제외가 모든 교육 관련 이름·문자열의 물리적 삭제를 뜻하지는 않습니다. 테스트 DB의 교육 과정 테이블이 비어 있고 차단된 검증 시드가 내용을 생성하지 않는지도 확인했습니다.

## 일반 사용자 및 관리자 기능

| 영역 | 확인한 범위 |
| --- | --- |
| 인증·계정 | 가입·승인·로그인, Google/Kakao/Naver SSO 상태값 검사와 세션 생성, OTP 등록·잘못된 코드 거부·OTP 로그인 |
| 커뮤니티 | 공지 및 교육과 무관한 Q&A 생성·조회·알림 |
| 권한 | 일반 사용자의 관리자 API 접근 차단, 제한 관리자 권한 상승 차단, 마지막 활성 관리자 보호·비활성 계정 세션 무효화 |
| 클라우드·프로젝트 | 모의 클라우드 기반 승인·VM 생성/삭제·다른 소유자 접근 거부·프로젝트 삭제 동시성 및 서비스/PoC 보호, 일괄 시작 선택 정책 |
| 일반 서비스 | 교육 목적지가 없는 서비스 메뉴, 일반 LLM 응답, HTTP/TCP 전달, 보안점검 보고서 계약 및 조회 전용 권한 |
| 설치·분리 | 이전 코어 데이터 마이그레이션, 암호화 자격증명 유지, 독립 디렉터리 내부 import, Podman/Docker 설치 계획 및 기존 설치 소유권·상태 경로 정책 |

전체 Node 테스트 **85개 통과, 실패 0, 건너뜀 0**입니다. 테스트 전용 로컬 PostgreSQL에 코어·활성 플랫폼·마이그레이션용 새 DB를 각각 생성해 실행했습니다. 인스톨러 Python 테스트 **19개 통과**, JavaScript 구문 검사와 프런트엔드 프로덕션 빌드도 통과했습니다.

재현 명령과 DB 환경변수는 [개발 안내](development.md)를 참고하세요. 주요 근거는 `tests/platform-integration.test.mjs`, `tests/integration.test.mjs`, `tests/edition.test.mjs`, `tests/community-workspace.test.mjs`, `tests/admin-permissions.test.mjs`, `tests/project-cleanup.test.mjs`, `tests/isolation.test.mjs`, `installer/test_installer.py`입니다.

## 실제 운영 검증 범위

SSO 공급자·LLM·클라우드 호출은 모의 응답으로 검증했습니다. 실제 공급자 키·콜백 URL 등록, OpenStack 연결과 자원 수명주기, 실제 Linux 컨테이너 설치·업데이트·복원, 메일 발송 및 모든 서비스별 동작은 설치 환경에서 추가 확인해야 합니다. 이번 검증은 원본 Terminal Lab의 모든 최신 변경을 자동으로 가져오거나 전체 기능의 실운영 동등성을 보장하는 작업은 아닙니다.

## 배포 정책

GitHub와 Gitea 커뮤니티 저장소는 모두 공개이며, 예제 사이트는 [터미널랩](https://www.terminal-lab.kr/)입니다. 예제는 교육 기능을 포함하는 원본 서비스의 참고 사이트이며 Community 배포본 자체와 구분합니다. 과거 교육 이력의 보관 저장소는 비공개로 유지합니다.

0.3.7 소스 ZIP에는 인스톨러와 파일별 `SHA256SUMS.json`을 포함하고 별도 `.zip.sha256`을 제공합니다. 커밋과 ZIP의 일치 여부 및 양쪽 릴리스 첨부 파일의 다운로드 해시는 배포 스크립트에서 검증합니다. 이미 게시된 이전 릴리스는 덮어쓰지 않습니다.

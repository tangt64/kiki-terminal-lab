# 프로젝트 정리 범위

관리자 → 자원·진단 → 클라우드 콘솔 관리의 **실제 OpenStack 자원**에서 프로젝트별 **프로젝트 전체 삭제** 버튼을 찾을 수 있습니다. 자원 보기를 펼치지 않아도 버튼과 범위 안내가 표시됩니다.

| 작업 | 삭제 범위 | 보존·주의 사항 |
| --- | --- | --- |
| 기록 제거 | 포털의 요청·승인 연결 기록 | 기본 동작은 실제 자원을 보존합니다. 추가 확인에서 OpenStack 자동 정리를 선택하면 실제 자원·프로젝트까지 정리합니다. |
| 인스턴스 정리 | 자원 상세의 개별 VM 삭제 버튼으로 선택한 VM 한 대 | 프로젝트·네트워크를 유지합니다. 볼륨은 기존 자동 삭제 설정에 따라 영향을 받을 수 있고, 임시·로컬 디스크 데이터는 사라집니다. |
| 프로젝트 전체 삭제 | 지원되는 VM·볼륨·프로젝트 소유 네트워크 등 잔여 자원, 이후 Keystone 프로젝트와 승인 연결 | 볼륨 데이터도 삭제됩니다. 사용자 계정과 별도 기록은 대상이 아닙니다. |

프로젝트 전체 삭제는 `admin:cloud` 권한 또는 전체 관리자 권한과 승인된 프로젝트 연결이 필요합니다. 같은 프로젝트의 승인 연결 기록을 모두 포함하고, `DELETE <프로젝트 이름>`을 정확히 입력한 뒤 별도로 실행 버튼을 눌러야 합니다. 닫기·취소·Escape는 삭제를 실행하지 않습니다.

실행은 기존 `/api/admin/self-service-project-requests/delete-records` 정리 경로를 사용합니다. 서버의 권한 검사, 검토 중 요청 처리, 진행 중인 포털 VM·컨테이너·DB·클러스터 관련 차단, 서비스/PoC 기본 프로젝트 보호 및 미선택 승인 연결 검사와 자원 정리 검증을 유지합니다. 별도의 강제 정리 권한이나 강제 삭제 옵션을 추가하지 않습니다.

표시된 자원 수는 조회 시점의 요약입니다. 서버가 실행 시 다시 확인하며 실패 시 기존 오류를 표시합니다. 일부 자원이 이미 정리된 뒤 실패할 수 있으므로 자동 원복되는 작업으로 간주하지 마세요. 실제 사용 전 백업·복원 경로와 대상 프로젝트를 확인하세요.
